# TinhToanMem
Dự án này tập trung vào việc xây dựng và đánh giá các mô hình học máy để giải quyết bài toán dự báo giá trị liên tục. Mục tiêu chính là áp dụng hai phương pháp có độ phức tạp khác nhau: Linear Regression  và Neural Network, từ đó đưa ra cái nhìn khách quan về hiệu quả của từng phương pháp trên cùng một tập dữ liệu.
